# Spec Delta

## Purpose

规定首关的实时三维城市观感、斜俯视黑洞效果、参考视频风格的中文信息反馈与基础声音，使玩法状态在竖屏画面中清晰可辨且资产授权可追溯。

## ADDED Requirements

### Requirement: 实时三维斜俯视城市
系统 SHALL 直接显示实时 3D 建筑、道路和地面，默认斜俯视画面应同时呈现建筑屋顶与侧面，而非使用预渲染 2D 建筑精灵。

#### Scenario: 观察商业建筑
- **WHEN** 玩家以默认透视镜头观察城市建筑
- **THEN** 建筑具有可见的三维体积、屋顶和侧面，并与道路及地面保持统一尺度

#### Scenario: 切换投影
- **WHEN** 用户切换至正交镜头
- **THEN** 同批实时三维对象继续显示，不退化为图片或改变其吞噬状态

### Requirement: 黑洞地面 Shader 与动画
系统 SHALL 使用贴地三维 Shader 和动画表现深色中心、旋转边缘及按阵营区分的彩色外圈，并配合物体倾斜、缩小和下沉过程。

#### Scenario: 黑洞移动与成长
- **WHEN** 黑洞在陆地或水面移动或扩大体型
- **THEN** 洞口保持贴地、彩色边缘可辨识，视觉半径与有效吞噬半径保持配置的一致关系

#### Scenario: 吞噬物体
- **WHEN** 物体进入吞噬过程
- **THEN** 其三维模型连续倾斜、缩小并向洞口下沉，完成后不再可见

### Requirement: 固定竖屏与中文 HUD
系统 SHALL 使用固定竖屏构图，在 Mac 窗口中显示参考视频风格的简洁中文 HUD，并适配安全区域和重要信息可读性。

#### Scenario: 正常对局显示
- **WHEN** 对局正在进行
- **THEN** HUD 显示倒计时、完成度、体型等级与经验、击倒数和本局金币，浮动摇杆不遮挡关键按钮

#### Scenario: 特殊事件反馈
- **WHEN** 发生升级、击倒、多重击倒、满级或高塔解锁
- **THEN** 系统显示与事件对应且不会混淆的中文视觉反馈

### Requirement: 打包开源中文字体
系统 SHALL 随项目打包具有明确开源授权的思源黑体或 Noto Sans SC 字体，不依赖 Mac 系统字体维持中文显示。

#### Scenario: 在无相同系统字体环境运行
- **WHEN** 游戏在未安装开发机字体的兼容环境启动
- **THEN** 中文首页、HUD 和结算仍使用随包字体正确显示，且授权文件可查阅

### Requirement: 基础事件音效
系统 SHALL 为吞噬、升级、击倒、高塔出现、胜利和失败提供可区分的基础音效，并允许用户调整或关闭音量。

#### Scenario: 触发玩法事件
- **WHEN** 任一配置音效的有效事件完成
- **THEN** 对应音效只播放一次，未完成的吞噬或重复结算不重复发声

#### Scenario: 静音设置
- **WHEN** 用户将音量关闭
- **THEN** 所有游戏音效停止输出，玩法与视觉反馈继续正常运行

### Requirement: 素材与授权可追溯
系统 SHALL 仅将已记录来源和授权的正式资源纳入游戏，候选素材与预览 MUST 保持不被自动导入。

#### Scenario: 新增正式模型、字体或音效
- **WHEN** 资源进入正式游戏目录
- **THEN** 清单记录其来源、授权、处理方式和使用位置，原始候选文件不被覆盖
