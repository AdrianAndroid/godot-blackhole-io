# Proposal

## Why

项目需要把参考视频中的一整局玩法转化为可自动验收的 Mac 单机原型，同时明确视频未展示规则的默认补全方案，避免在素材、随机地图和核心循环之间反复返工。当前候选素材已经齐备，但尚无可运行工程、统一玩法规格和实现任务，因此需要先建立完整单局闭环的变更契约。

## What Changes

- 建立 Godot 4.x Mac 竖屏原型，包含简洁首页、10 分钟对局、暂停、胜负结算和重试；抖音小游戏适配后置，不作为本轮硬门槛。
- **BREAKING**：将最初的 `Area2D`、2D 精灵和 CanvasItem Shader 约定调整为实时 3D 城市场景、`Node3D`/`Area3D`、XZ 地面平面逻辑和 3D 地面 Shader；不采用完整 3D 刚体物理。
- 使用 Mobile 渲染后端，提供默认透视与可切换正交镜头；镜头跟随玩家并随体型成长平滑拉远。
- 提供浮动摇杆和鼠标模拟、水面自由通行、地图边界限制、仅手动暂停；窗口失焦不自动暂停。
- 实现按实际半径判定的吸附、倾斜、缩小、下沉和消失后结算，体型等级为 1～19 级；不可吞建筑不阻挡移动。
- 使用 Commercial、Roads、Suburban、Industrial 中适合首关的 CC0 模型，混合彩色建筑变体，按街区模板和随机种子生成地图，建筑不补生成。
- 放置 4 个沿固定路线移动且不成长的彩色假对手，采用大吞小、玩家死亡失败、击倒数与完成度奖励规则。
- 按目标分数计算完成度，以本局建筑目标总分约 75% 为适中难度基准；达到 100% 解锁金色最终高塔，高塔出现后即可吞噬并获胜。
- 保留本局金币、击倒与多重击倒反馈、目标指引和胜负结算，不实现跨局消费、商店或永久养成。
- 制作参考视频风格的简洁中文 HUD，打包开源中文字体，加入吞噬、升级、击倒、高塔出现和胜负基础音效。
- 失败重试沿用地图种子，从首页开始新局时更换种子；全部逻辑、整局、输入、截图与性能验收自动执行，不要求用户手工测试。
- 初始化本地 Git，不关联远程仓库；原始素材 ZIP、清单、授权与预览入库，解压候选目录忽略，正式使用资源单独入库。

## Capabilities

### New Capabilities

- `match-flow`: 首页、对局状态、10 分钟倒计时、手动暂停、胜负结算及同种子重试。
- `hole-controls`: 浮动摇杆、鼠标模拟、水面通行、地图边界、跟随镜头和投影切换。
- `swallowing-growth`: 半径资格、吸附下沉动画、结算时机、体型经验与 19 级上限。
- `city-generation`: 街区模板、种子随机、四包素材分区、固定建筑实例与重试地图复现。
- `opponent-encounters`: 4 个固定路线假对手、大吞小、死亡失败、击倒数与多重击倒。
- `level-objectives`: 目标分、适中难度、完成度、本局金币、最终高塔解锁与胜利。
- `game-presentation`: 实时 3D 城市场景、黑洞 Shader、中文 HUD、开源字体和基础音效。
- `automated-verification`: 无人工参与的规则、随机地图、完整对局、输入、视觉基线与性能验收。

### Modified Capabilities

无现有 capability specs。

## Impact

- 新建 Godot 工程、3D 场景、GDScript 管理器、输入与镜头、地图生成、对手、成长、目标、HUD、音效和自动测试结构。
- 直接导入选中的 GLB 模型与纹理；不再进行批量 2D 精灵预渲染。素材来源与授权继续由 `assets/ASSET_MANIFEST.md` 跟踪。
- 新增开源中文字体和 CC0 基础音效依赖，分别记录授权；UI Pack 仅作组件参考，不作为整套最终 HUD。
- 新增本地 Git 与忽略规则；候选素材解压目录保留在项目本地但不提交。
- 本轮不实现真人联机、抖音导出、广告、支付、商店、跨局金币、永久升级、多关卡、账号、排行榜、分享和全图无约束程序生成。
